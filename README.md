# Proiect IoT – Control NeoPixel și Servomotor

Acest proiect demonstrează controlul unui inel NeoPixel și al unui servomotor folosind un microcontroler Arduino și o interfață web dezvoltată în Flask.

## Structură

* **Arduino** – gestionează LED-urile și servomotorul
* **Flask (Python)** – server web local pentru interacțiune
* **Interfață Web** – butoane pentru control culoare și mișcare

## Cerințe

* Arduino Uno
* NeoPixel Ring (16 LED-uri)
* Servomotor
* Python + Flask + pyserial
* Arduino IDE

## Funcționalități

* Selectare culoare LED (red, green, blue)
* Control poziție servomotor
* Comunicare serială bidirecțională
